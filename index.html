About the Dev

One person. Four games. Infinite slices.

Pizza Hero Gaming is a one‑person studio — me, a code editor, and an unreasonable amount of pizza imagery. I build small, web‑first games that run in a browser tab, install as PWAs, and don't ask anyone to make an account.

My favorite kind of game is the one you can pick up in 30 seconds and still be discovering something new an hour in. Wallop is the flagship — a 3D bullet‑heaven where you play the Pizza Delivery Hero — and the rest of the lineup ranges from dark alchemist crafting to chill semi‑idle. More on the way.
